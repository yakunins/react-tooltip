## Breaking changes

Several props are renamed. Update your code as follows:

| Before                           | After                                      |
| -------------------------------- | ------------------------------------------ |
| `trigger`                        | `triggers`                                 |
| `autoFlip`                       | `flip`                                     |
| `timings.delayShow`              | `timings.showDelay`                        |
| `timings.delayHide`              | `timings.hideDelay`                        |
| `timings.clickCloseGuard`        | `timings.clickGuard`                       |
| `timings.minVisibleDuration`     | `timings.minVisibleTime`                   |
| `bubbleStyle.transitionDuration` | `animationDuration` (now a top-level prop) |

```diff
- <Tooltip trigger={['click']} autoFlip={false} timings={{ delayShow: 500 }}
-   bubbleStyle={{ transitionDuration: '0.3s' }} content="Hi">
+ <Tooltip triggers={['click']} flip={false} timings={{ showDelay: 500 }}
+   animationDuration="0.3s" content="Hi">
```

Also:

- The raw `.css` files are no longer shipped in `lib/`. The components inject their CSS themselves, so this only affects code that imported those files directly.
- The `--tooltip-transition-duration` CSS variable is gone; use `animationDuration`.
- **Class names changed**, for custom CSS. Each part keeps one class and exposes its state as data attributes, which also avoids clashing with other libraries (Bootstrap has its own `.tooltip`):
  - popover: `.tooltip` → `.tooltip-popover`;
  - `.placement-top` → `[data-placement='top']` (same for `bottom`, `left`, `right`);
  - `.arrow-start` / `.arrow-end` → `[data-arrow='start']` / `[data-arrow='end']`;
  - `.anchor-hidden` → `[data-anchor-hidden]`;
  - bubble: `.corners-5` → `[data-corners='5']`.
- React 18 or newer is now required: the peer dependency is raised from `>=16.8` to `>=18` (the code uses `useId`, `useInsertionEffect` and `useSyncExternalStore`).

## Features

- **Smooth handover between animations.** The fade and the flip slide now run independently. When the tooltip closes, or its anchor scrolls out of sight, during a flip, the bubble fades out from its current opacity while the slide finishes.
- **Escape closes only the topmost tooltip**, and stops there, so a surrounding dialog closes on the next press instead of the same one.
- **Content Security Policy support.** The injected `<style>` tags pick up the page's CSP nonce automatically, from `<meta property="csp-nonce">` or a `<script nonce>`. No configuration.
- **`TooltipPopover`**: the top-layer popover is now its own exported component, alongside `TooltipAnchor` and `TooltipBubble`.
- **Graceful degradation.** Only CSS anchor positioning and the Popover API are required for the styled tooltip. Without the Web Animations API it shows and hides instantly; without `IntersectionObserver`, flipping and the hidden-anchor fade are off.

## Fixes

- Screen readers now announce the tooltip on a focusable child (for example a wrapped `<button>`). `aria-describedby` used to sit on the wrapper, which never received focus in that case.
- An `anchorRef` element that mounts after the tooltip, or is swapped for another element, is now wired up correctly (listeners, `anchor-name`, `aria-describedby`).
- Rich `content` renders only after the first open, so many closed tooltips cost little. Plain-text content still renders up front, since it is the `aria-describedby` description.
- The injected stylesheet is no longer re-hashed on every render.
